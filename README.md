# Вычисление расстояния между точками (C++)

Консольное приложение, которое создает две точки на плоскости с заданными координатами (x, y) и вычисляет расстояние между ними.

## Описание алгоритма

1. **Создание структуры:** Объявлена структура `Point`, которая содержит две переменные с плавающей точкой `x` и `y` (координаты).
2. **Ввод данных:** Пользователь вводит координаты для двух точек (`p1` и `p2`).
3. **Вычисление расстояния:** Расстояние вычисляется по теореме Пифагора:
   - Сначала находится разность координат по оси X (`dx = x2 - x1`) и по оси Y (`dy = y2 - y1`).
   - Затем вычисляется квадратный корень из суммы квадратов: `sqrt(dx^2 + dy^2)`.
4. **Вывод результата:** На экран выводится расстояние между двумя заданными точками.

## Пример работы

```text
=== ВЫЧИСЛЕНИЕ РАССТОЯНИЯ МЕЖДУ ТОЧКАМИ ===

Введите координаты первой точки (x и y через пробел): 0 0
Введите координаты второй точки (x и y через пробел): 3 4

Расстояние между точками:
A(0; 0) и B(3; 4)
Расстояние = 5
